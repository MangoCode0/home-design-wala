# Home Design Wala (Step 1: homepage foundation)

## Run it
1. Install Node.js (version 18 or newer).
2. In this folder run:  npm install
3. Then run:           npm run dev
4. Open the address shown in the terminal (usually http://localhost:5173).

## Folders
- src/components/  one folder per section (a .jsx file and a .css file each)
- src/data/        dummy content (projects, categories, services, steps, testimonials)
- src/hooks/       small reusable logic (useReveal)
- public/images/   placeholder pictures. Replace them with real photos, keeping the same
                   file names, or change the paths in src/data/.
- src/index.css    brand colors, fonts, shared button styles
